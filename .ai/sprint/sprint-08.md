# Sprint 08 - POS MVP

## Goal

Build the minimum POS required for daily operations.

## Business Problem

The business still depends on a third-party POS application.

## Scope

- Customer Registration
- Create Order
- Service Selection
- Weight Input
- Payment Recording
- Receipt Printing

## User Stories

As a cashier,

I want to register customer orders,

so transactions are managed inside LaundryOS.

## Acceptance Criteria

- Order created
- Payment recorded
- Receipt generated

## Technical Tasks

- POS UI
- Order Form
- Payment Module
- Receipt Module

## Deliverables

- POS MVP

## Out of Scope

- Inventory
- Membership
- Analytics

## Definition of Done

- Daily transactions can be completed using LaundryOS
