# Sprint 02 - Backend Foundation

## Goal

Build the backend core services.

## Business Problem

Business data must be centralized inside the backend instead of the WhatsApp Gateway.

## Scope

- Customer Module
- Order Module
- REST API
- Swagger
- Database Migration
- Repository Layer

## User Stories

As the backend system,

I want customer and order data stored centrally,

so every module uses the same source of truth.

## Acceptance Criteria

- Customer CRUD
- Order CRUD
- Migration works
- Swagger generated
- REST API available

## Technical Tasks

- Create customer module
- Create order module
- Create repositories
- Create services
- Create handlers
- Configure Swagger

## Deliverables

- Backend API

## Out of Scope

- AI
- Dashboard
- POS
- Pickup Workflow

## Definition of Done

- CRUD APIs tested
- Swagger updated
