# Sprint 05 - Dashboard

## Goal

Provide a simple web dashboard for the owner and staff.

## Business Problem

Operational data is scattered across WhatsApp conversations.

## Scope

- Login
- Customer List
- Orders
- Pickup Queue
- Laundry Status

## User Stories

As the owner,

I want to monitor daily operations,

so I know what work is pending.

## Acceptance Criteria

- Dashboard accessible
- Orders displayed
- Customers displayed
- Pickup queue displayed

## Technical Tasks

- Authentication
- Dashboard UI
- API Integration
- Tables
- Filters

## Deliverables

- Dashboard MVP

## Out of Scope

- Analytics
- Inventory
- POS

## Definition of Done

- Dashboard usable by staff
