# Sprint 04 - Pickup Management

## Goal

Allow customers to request laundry pickup through WhatsApp.

## Business Problem

Pickup requests are currently handled manually.

## Scope

- Pickup Request
- Customer Validation
- Address Collection
- Pickup Schedule
- Order Creation
- Group Notification

## User Stories

As a customer,

I want to request laundry pickup,

so I don't have to visit the store.

## Acceptance Criteria

- Pickup request completed
- Order created
- Notification sent to staff group

## Technical Tasks

- Pickup flow
- Conversation state
- Order creation
- Notification service

## Deliverables

- Pickup Module

## Out of Scope

- Payment
- AI
- POS

## Definition of Done

- Pickup can be completed end-to-end
