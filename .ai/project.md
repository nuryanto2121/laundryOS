# LaundryOS

LaundryOS is a personal software project built for FAN Laundry Station.

The project is intended to replace repetitive manual operations.

This project is NOT a WhatsApp Bot.

The WhatsApp Bot is only one interface.

LaundryOS will become a complete Laundry Management System.

Future modules include:

- WhatsApp Gateway
- Customer Management
- Pickup Management
- Delivery Management
- Dashboard
- POS
- QRIS Payment
- AI Assistant
- Membership
- Analytics
- Multi Branch
- SaaS

Primary Goal

Automate laundry operations while keeping the system simple.
